# Nan Map

Nan Map 是一个旅游攻略地图编辑器，目标是帮助用户快速整理旅行点位、规划路线，并导出一张清晰易分享的行程地图。

当前项目处于「地图编辑器原型」阶段：已经具备地图层、点位编辑、路线规划、点位搜索、工具面板、白板基础绘制和模板导入导出交互；全局地图搜索、图片导出、账号付费等能力仍在规划或待接入阶段。

## 产品目标

- 让用户用地图而不是长文本来组织旅行攻略。
- 支持添加五角星、圆底、圆底镂空五角星、圆底镂空数字等不同视觉点位。
- 支持基于点位生成路线，并展示驾车、公交、骑行、步行等交通方案。
- 支持在地图上叠加白板内容，例如文字、图片、照片气泡、水印和分层标注。
- 支持导出图片或模板，方便分享、复用和二次编辑。

## 技术栈

- 前端框架：Next.js 16、React 19、TypeScript。
- UI 方案：Tailwind CSS 4、shadcn/ui 风格组件、lucide-react 图标。
- 地图能力：高德地图 Web API，通过 `public/map.js` 暴露浏览器侧地图桥接接口。
- 白板能力：使用 KonvaJS / react-konva 实现地图上方的白板层，白板对象通过 `window.map` 暴露的坐标转换接口与地图经纬度绑定。
- 后端能力：规划由 Node.js 提供账号、购买、授权和模板服务，当前尚未接入。
- 多端方向：后续考虑 React Native；文档默认描述桌面端，小屏适配写在括号中。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000` 查看页面。

## 地图配置

项目不会把真实高德配置提交到仓库。首次运行地图前，需要基于示例文件创建本地配置：

```bash
GD_MAP_KEY="你的 Key" GD_MAP_SECURITY="你的安全密钥" npm run prepare:map
```

该命令会用环境变量替换 `public/map.example.js` 中的占位符并生成
`public/map.js`。GitHub Pages 工作流会从 Actions Secrets
`GD_MAP_KEY` 和 `GD_MAP_SECURITY` 自动执行同一生成步骤。

注意：`public/map.js` 位于浏览器公开目录，不适合存放不可泄露的后端密钥。当前它只应作为本地开发桥接文件使用，生产环境需要重新设计密钥管理和域名白名单策略。

## GitHub Pages 部署

推送到 `main` 后，GitHub Actions 会构建静态站点、使用 JS VM 加固
`map.js`，再把最终产物强制更新到 `gh-pages` 分支。仓库的 Pages 发布来源应设置为
`gh-pages` 分支的 `/ (root)`。

## 当前已实现

- 地图层：加载高德地图，渲染点位；用户创建路线后会保存并保留在地图上，点击地图线路只打开路线面板，线路选择回到路线弹框内完成，只有编辑当前线路时才会更新该线路，地图或规划未完成时不显示默认直线层。
- 点位编辑：支持新增点位、选择点位、修改名称、拖动未锁定点位；点位位置不能通过点击地图空白处修改。
- 点位锁定：锁定后点位不可拖动，名称、样式、颜色和地点绑定不可编辑；地图点位使用实线圆圈表示锁定，虚线圆圈表示未锁定。
- 点位样式：支持五角星、圆底、圆底镂空五角星、圆底镂空数字四类视觉样式，并可独立选择颜色。
- 点位详情面板：支持点击概览名称聚焦线式名称输入、搜索展开、小屏搜索浮层；线路规划入口位于右侧按钮组，点击后展开未连接点位列表，也可继续点击地图点位完成连接。
- 地图搜索：点位面板搜索按钮位于弹框层按钮组栏；点击后向右展开搜索框，支持城市和地点关键词输入，结果来自高德地点搜索 API，选择结果后绑定到当前点位。
- 工具面板：支持点位、路线、图层三个模式；按钮组栏桌面端位于面板右侧，小屏端位于底部，默认保留新增点位按钮，收起后不再显示单独展开图标，并按面板状态调整地图视野留白。
- 路线规划面板：通过高德路线规划 API 支持驾车、公交、骑行、步行四类切换模式；未创建线路时显示空态，不默认规划路线；每条规划成功的点到点线路都会留在地图上，规划其他线路不会清除旧线路；路线面板内提供交通方式切换和线路颜色编辑，已保存线路列表通过右侧按钮组悬停或点击展开，点击列表项会选中对应线路并进入编辑语义，右侧按钮组支持删除当前线路；切换交通方式只更新当前编辑线路；总览模式只展示每条线路的整体方案，选中某条线路后才展开详细步骤；高德自带起终点气泡不显示；驾车展示多个备选线路、距离、预计时间和费用，公交展示公交/地铁/有轨交通/打车组合，骑行提示自行车和摩托车/电动车限行风险，步行展示路线距离和预计耗时。
- 白板层：已接入 KonvaJS，支持钢笔、铅笔、蜡笔三种笔触的自由绘制，右侧白板工具栏提供调色盘、吸色和油漆桶填充工具，并支持文字颜色、字体、艺术字体、字重、字号编辑、照片气泡、选择拖动、缩放、擦除和水印平铺；白板对象使用经纬度存储，地图平移或缩放后会重新投影，文字和图片保持稳定视觉尺寸。
- 导入导出：左上角导入/导出按钮会打开工具面板里的导入导出模块，支持导出包含点位、已保存线路、高德路线规划缓存、线路颜色、白板对象、水印和地图视野的 JSON 模板，也支持复制 `NANMAP1.` P2P 分享码；导入时可粘贴 P2P 分享码或选择 JSON 文件，导入后恢复地图、路线和白板状态。
- 图层原型：已有地图图层、覆盖层、卫星影像、实时路况等控件；白板水印大小和平铺已接入真实状态，其余图层开关仍以占位为主。

## MVP 功能拆解

### 地图层

- 提供高德地图底图。
- 新增标记按钮由工具面板按钮组提供（桌面端在面板右侧，小屏端在底部工具区）。
- 点位使用圆形无背景容器，可按类型设置图标、描边、颜色和锁定态。
- 点击点位打开点位详情工具面板。
- 点击地图路线打开路线规划详情工具面板；具体线路选择在路线面板内完成。

### 地图搜索

- 搜索区分为城市输入和地点搜索。
- 城市默认取当前地图中心点所在城市。
- 用户修改城市后，应记录上一次选择，并影响后续地点搜索范围。
- 搜索框输入后调用高德搜索接口，结果以列表展示。
- 选择搜索结果后，将地点绑定到当前点位，并更新经纬度、名称和地址。
- 当前版本先完成点位面板的搜索框能力；搜索按钮放在弹框层按钮组栏，点击后向右展开搜索框。

### 定位能力

- 定位按钮作为开关：开启后获取用户当前位置，关闭后停止实时定位。
- 开启定位后，点击任一点位应从当前位置到该点位生成路线。
- 定位失败、权限拒绝、浏览器不支持时需要提供明确反馈。

### 工具面板

- 面板支持展开和收起。
- 桌面端从左侧展开，小屏从底部展开。
- 面板内操作不能遮挡地图关键点位和路线。
- 桌面端按钮组栏位于工具面板右侧，小屏端位于底部，其他子组件展开时向这个组里添加按钮，这个按钮组栏默认只有一个添加点按钮。
- 按钮组栏不随折叠消失，展开时跟随面板有一个过渡效果。

### 点位详情面板

- 名称输入默认是一条线式输入框，点击概览名称时进入名称编辑状态。
- 锁定点位后不能拖动，也不能修改名称或重新绑定地点。
- 搜索按钮展开地点搜索区；小屏时搜索区应避免挤压主面板内容。
- 点位样式支持五角星、圆底、圆底镂空五角星、圆底镂空数字，并可独立选择颜色。
- 线路规划按钮位于点位详情右侧按钮组，点击后在右侧展开尚未和当前点连接过的点位集合。
- 点击列表中的点位可立即创建点到点路线；展开期间也可以直接点击地图上的其他点位完成连接。

### 路线规划面板

- 提供驾车、公交、骑行、步行四类交通方式，切换按钮位于线路弹框内容区。
- 提供线路颜色编辑；未设置自定义颜色时，地图线条按交通方式使用默认颜色。
- 未创建线路前不默认规划路线；路线仅由点位详情的线路连接或定位目标触发。
- 驾车：展示多个备选线路、距离、预计时间和费用信息。
- 公交：展示公交、地铁、有轨交通、打车等组合方案。
- 骑行：区分自行车/摩托车，并展示限行或禁行提醒。
- 步行：展示步行路线、距离和预计耗时。
- 总览模式只显示每条线路的整体中转或行程方案；选中某条线路后，才显示这条线路的详细步骤。
- 点击地图上的线路时，只打开线路弹框；线路选择在弹框里的已保存线路列表中完成。
- 线路编辑状态下需要提供删除按钮，用于删除当前线路连接并清空地图路线覆盖物。
- 已经成功规划的点到点线路需要保存并保留在地图上；创建或规划其他线路时不能清除旧线路。
- 切换交通方式、选择备选方案等编辑动作只更新当前选中的线路，不影响其他已保存线路。
- 当前版本通过 `public/map.js` 暴露的 `window.map.planRoute` 调用高德路线规划插件获取路线 path，再通过 `window.map.setRoutes` 批量绘制已保存线路；切换交通方式时旧请求会失效，当前编辑线路会被新模式结果替换，其他已保存线路保持不变，且不显示高德路线插件自带的起终点气泡；地图或规划未完成时不使用起终点直线兜底。

### 白板层

- 白板层位于地图层和工具面板之间，与地图坐标保持 1:1 绑定。
- 地图拖动和缩放时，白板对象要保持和地图点位的相对关系。
- 文字、图片等对象在地图缩放时应保持视觉尺寸稳定。
- 当前版本使用 KonvaJS 渲染白板对象：移动工具让事件穿透给地图，画笔工具支持钢笔、铅笔、蜡笔三种笔触，工具栏调色盘统一控制新建线条和文字颜色，吸笔可从线条或文字吸取颜色，油漆桶可把当前颜色填充到线条或文字上，其他工具由白板层接管选择、图片导入和擦除。
- 支持照片气泡、绘制对象分层、水印大小和水印平铺。

### 导入导出

- 导出图片：根据点位、路线和白板对象计算包围盒。
- 导出前提供截图编辑器，可调整导出区域和缩放比例。
- 当前版本已完成模板导出：将地图点位、已保存路线连接、高德路线方案缓存、线路颜色、地图视野、白板对象和白板水印导出为 JSON。
- 当前版本已完成 P2P 分享：把同一份模板编码成 `NANMAP1.` 分享码，其他用户粘贴后即可导入恢复。
- 当前版本已完成模板导入：支持粘贴 P2P 分享码或选择 JSON 文件，导入后恢复可编辑状态。
- 后续如 JSON 性能不足，再评估二进制或压缩格式。

## 逻辑和 UI 风险

- 功能状态容易误判：原文所有模块都标为 `[x]`，但不少只是规划或静态原型，容易让后续开发误以为已经完成。
- 锁定态需要持续覆盖后续新增字段：后面如果补充备注、照片、标签等点位属性，需要继续遵守锁定后不可编辑的约束。
- 地图搜索依赖高德 API 配置和权限：当前先完成点位面板搜索框，后续需要扩展到全局地图搜索和更多 POI 字段。
- 定位依赖浏览器权限和系统定位服务：权限拒绝、定位不可用或请求超时时会进入错误态，后续还需要补充更细的重试和引导体验。
- 路线规划依赖高德 API 配置和权限：驾车支持多点规划，公交、骑行、步行在多点场景下按相邻点分段规划后合并展示。
- 多点路线顺序仍待设计：当前线路连接以两点为主，后续多点路线需要补充明确的排序和起终点编辑能力。
- 白板层事件冲突需要提前设计：绘制、拖动地图、拖动点位三者都依赖鼠标/触摸事件，需要明确模式优先级。
- 小屏空间紧张：底部面板、搜索结果、地图点位标签和新增按钮可能互相挤压，需要为移动端单独设计工具区。
- 导出边界复杂：导出包围盒需要同时计算地图点位、路线、白板对象和水印，否则容易裁掉内容。
- 配置安全：高德 key 和 securityJsCode 不应提交到仓库；生产环境需要域名白名单和服务端配置策略。

## 开发约定

- `app/page.tsx` 只保留路由入口；地图编辑器这类顶层业务组件放到 `app/components`，再按面板、工具栏、地图层继续拆分。
- 工具面板按钮组只负责承载默认新增按钮和当前面板内容注册的工具 slot；点位、路线等子组件自己注册和替换各自的工具按钮。
- 点位详情和路线详情分别由 `MarkerDetail`、`RouteDetail` 独立组件承接；`EditorPanel` 只负责面板壳、模式切换和公共搜索浮层。
- 组件默认保持小而直接，只在复用或复杂度明显增加时拆分子组件。
- 组件文件使用 `.tsx`；样式优先沿用 Tailwind 和全局 CSS，若后续引入 Sass 再统一约定 `.sass` 或 `.scss`。
- 先补齐 MVP 闭环，再做账号、购买、授权和多端复用。
- UI 控件优先使用熟悉的图标按钮、切换控件、标签页、输入框、滑杆和复选框。
- 涉及地图、路线和白板坐标的功能，需要优先保证状态模型清晰，再补视觉细节。

## 下一步建议

1. 扩展高德搜索能力，让全局地图搜索、周边搜索和点位面板搜索共用同一套结果模型。
2. 定义路线数据模型，区分“点位顺序折线”和“高德交通规划方案”。
3. 为白板层设计事件优先级：地图拖动、点位拖动、白板绘制不能互相抢事件。
4. 梳理移动端工具区，避免底部面板展开后遮挡主要点位和路线。
